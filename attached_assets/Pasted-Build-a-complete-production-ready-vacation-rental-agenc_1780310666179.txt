## Technical Requirements
- HTML/CSS/JS (vanilla) OR React — choose whichever produces the most polished result
- Fully responsive (mobile-first)
- Smooth scroll navigation
- Sticky header with logo + nav links
- Subtle scroll-reveal animations on property cards and sections (use Intersection Observer or AOS library)
- Image placeholders must be clearly labeled so owner can swap in real photos easily
- Use CSS custom properties (variables) throughout for easy theming
- Add a grain/noise texture overlay on the hero using CSS (pseudo-element with SVG filter or background noise)
- The hero should have a subtle parallax effect on scroll

## Image Handling Note
The owner will provide real photos manually. All image tags should have:
- A descriptive alt text
- A clear HTML comment above them: <!-- REPLACE: upload your photo here -->
- A styled placeholder div as fallback with the property name shown

## Aesthetic Direction
Mediterranean coastal luxury — warm, editorial, organic. Avoid anything that looks like a generic template. Use generous whitespace, large elegant typography for headings, and subtle earthy textures. The bougainvillea flower (magenta/pink) can be used as a subtle decorative accent motif in dividers or icons.
